#weekly ARGprofiling for great bay data

This repository contains R code for analyzing weekly ARG metagenome data. This data is from September - December 2025 of monthly water samples from 7 sites (MAIN, LAMP, WIS, NBL, JEL, HILT, CML) in the Great Bay watershed. The reads were processed using the ARGprofiler pipeline. The resulting data was loaded into R for statistical analysis.
